One image that sums up Thursday 26 November 2026: a front-page newspaper
infographic with 36 real, sourced world-news stories across 9 regions —
the US tariff plan for 14 partners, Macy's 100th parade postponed by a
nor'easter, the Cairo tanker fire, Houthi strikes on Saudi oil sites, the
AI stock sell-off, India's 18th anniversary of the 26/11 attacks, and
Gukesh–Sindarov Game 3 — plus three drawn lead scenes, a world map with
every story's place, a UTC timeline of the day, and a date check. The
image is drawn by a Python script (Pillow) from the story list in
`compose.py`; `main.ts` copies the finished PNG into the output directory
and validates it.

## Run it

```sh
python3 compose.py
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
